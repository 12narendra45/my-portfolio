# Venkata Narendra Chakka Portfolio

A premium dark-themed, static portfolio website for Venkata Narendra Chakka built with HTML5, CSS3, and vanilla JavaScript.

## Files

- `index.html` — page structure and sections
- `style.css` — visual design, responsiveness, animations, and premium styling
- `script.js` — typing effect, navigation, scroll interactions, and motion logic

## Run locally

Open `index.html` directly in a browser, or serve the folder with a local web server:

```bash
cd portfolio
python -m http.server 8000
```

Then open: `http://localhost:8000`

## Notes

- The portfolio uses placeholder assets and paths for the resume and project/logo files.
- Replace files in `assets/` with real assets when available.
- The contact form is a static placeholder and opens the default mail client when submitted.
